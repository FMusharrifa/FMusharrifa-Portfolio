ACADEMIC / WEB DEVELOPMENT PROJECT

Tourism Website

A tourism website designed to promote Sri Lankan travel destinations with a clean, responsive interface. It presents destination guides, travel information and a mobile-friendly layout that works smoothly across all screen sizes.

HTML5CSS3JavaScriptResponsive DesignGit

Project Highlights & Technical Implementation

  • Responsive Layout: Fluid grid and flexible typography built with modern CSS to deliver a consistent experience on mobile, tablet and desktop.
  • Interactive Destination Gallery: JavaScript-driven image gallery with smooth transitions and lightbox-style previews for each attraction.
  • Clean Navigation: Sticky header and section anchors for quick access to destinations, travel tips and contact details.
  • Performance Focused: Optimised images and minimal dependencies to keep page load times low across devices.

Key Capabilities & Features

  • Destination showcase pages
  • Responsive mobile-first design
  • Interactive image gallery
  • Contact form with validation
  • Smooth scroll navigation
  • Cross-browser compatibility

FULL-STACK / MEAN STACK PROJECT

DailyFlow – Task Management

DailyFlow is a task management web application that helps users organise their day, track progress and stay focused. Built on the MEAN stack, it provides a REST API backend with an Angular frontend for a fast, single-page experience.

MongoDBExpress.jsAngularNode.jsREST APIJWT Auth

Project Highlights & Technical Implementation

  • Secure Authentication: JWT-based login and registration with hashed passwords and protected API routes.
  • REST API Architecture: Express.js backend with cleanly separated routes, controllers and models for maintainable code.
  • Reactive Frontend: Angular components with services and RxJS for real-time task updates without page reloads.
  • Data Persistence: MongoDB with Mongoose schemas for tasks, users and progress tracking, including input validation.
  • Progress Dashboard: Visual summary of completed vs pending tasks with daily streaks to encourage consistency.

Key Capabilities & Modules

  • User registration & login
  • Create, edit & delete tasks
  • Mark tasks complete
  • Progress tracking dashboard
  • Daily streaks & reminders
  • Secure JWT authentication
  • REST API integration
  • Responsive Angular UI
